## 1. 底盘模块 chassis.c/h 详解

### 1.1 数据结构与宏（chassis.h）

```c
// 遥控给定参数（麦轮解算的中间量）
typedef struct {
    int16_t RemoteLefUpSpeed;    // 左上轮给定速度
    int16_t RemoteLefDoSpeed;    // 左下轮给定速度
    int16_t RemoteRigUpSpeed;    // 右上轮给定速度
    int16_t RemoteRigDoSpeed;    // 右下轮给定速度
} RemoteParam_Struct;

// 底盘最终输出参数
typedef struct {
    int16_t LimtOutValue;          // 功率限制后所有电机输出量总和
    float   MergeFinalOutValue;    // 四电机输出绝对值和
    int16_t LefUpFinalOutValue;    // 左上最终输出（CAN 电流指令）
    int16_t LefDoFinalOutValue;    // 左下最终输出
    int16_t RigUpFinalOutValue;    // 右上最终输出
    int16_t RigDoFinalOutValue;    // 右下最终输出
} ChassisParam_Struct;

typedef enum {
    CHASSIS_VECTOR_FOLLOW_GIMBAL_YAW,   // 底盘跟随云台相对角度（默认模式）
    CHASSIS_VECTOR_revolve,             // 小陀螺自旋
} chassis_mode_e;
```

关键宏：

| 宏 | 值 | 含义 |
|----|-----|------|
| `A6020_M` | 1300 | yaw 云台电机（GM6020）编码器中值 |
| `v_revolve` | 5000 | 自旋模式的固定旋转速度 |
| `v_max` | 4000 | 键盘模式下最大线速度 |
| `HIGH_RmeoteSpeed` | 660 | 键盘 W/S/A/D 附加速度（=遥控满行程） |
| `NORMAL_RemoteSpeed` | 200 | （定义未用） |
| `PowerLimtParam` | 6.0 | 功率限制系数：limit = buffer² × 6 |
| `MaxGivenSpeed` | 7500 | 单个电机目标转速上限 |
| `ChassisP / I / D` | 6.0 / 0.1 / 0.0 | 底盘速度环 PID（注意：实际用的是 pid_init.c 里的 5/0.2/1，此宏未被使用） |
| `ChassisILim` / `MaxOutValue` | 4000 / 12000 | （定义未使用，PID 限幅在 pid_init.c） |

### 1.2 任务主循环（chassis_task，2ms 周期）

```c
void chassis_task(void *argument) {
    c = get_motor_control_point();       // 电机反馈
    RC = get_remote_control_point();     // 遥控器
    imu = gyroscope_control_point();     // 陀螺仪（本函数未使用，声明而已）
    G_mode_chassis = get_gps_mode_data_point();          // GPS/自瞄模式
    G_control_command_chassic = get_gps_command_data_point(); // 导航底盘命令
    while (1) {
        chassis_set_mode(&chassis_mode);   // 1. 模式切换
        chassis_set_control();             // 2. 速度解算（follow 模式）
        chassis_set_v();                   // 3. 速度解算（revolve 模式）
        ChassisController();               // 4. 限幅 + PID + 功率限制
        if (toe_is_error(DBUS_TOE)) {      // 5. 遥控器掉线 → 发零
            CAN_cmd_chassis(0, 0, 0, 0);
        } else if (RC->rc.s[1] == 0x02) {  // 右拨杆 DOWN → 底盘锁死（键盘云台模式）
            CAN_cmd_chassis(0, 0, 0, 0);
        } else {
            CAN_cmd_chassis(chassisparam.LefUpFinalOutValue,
                            chassisparam.RigUpFinalOutValue,
                            chassisparam.LefDoFinalOutValue,
                            chassisparam.RigDoFinalOutValue);
        }
        osDelay(2);
    }
}
```

> 注意：2 和 3 是两个互斥分支（各自函数内部判断 chassis_mode），每周期只生效一个。
> 发送参数顺序为 (左上, 右上, 左下, 右下)。

### 1.3 模式切换 chassis_set_mode

优先级从高到低：

1. `s[1] == 0x01`（右拨杆 UP）→ `CHASSIS_VECTOR_revolve` 小陀螺
2. `s[1] == 0x03`（右拨杆 MID）→ `CHASSIS_VECTOR_FOLLOW_GIMBAL_YAW` 跟随
3. `s[1] == 0x02`（右拨杆 DOWN，键盘模式）：
   - 按 F 键 → revolve，按 R 键 → follow
   - 若 GPS 模式 `G_mode_chassis->Chassis_Mode == 0x0A` → revolve，否则 follow

### 1.4 跟随云台模式速度解算 chassis_set_control

**云台 yaw 角度差（底盘跟随修正量）：**

```c
A6020_M1 = c->can1_motors.yaw.ecd - A6020_M;   // yaw 电机相对中值的编码器差
// 归一化到 ±4046（半圈），处理跨零跳变
if (A6020_M1 >= 4046 || A6020_M1 <= -4046) { ... ±8191 修正 ... }
A6020_angle = PID_Calc(&all_motor_pid.pid_follow_angle, A6020_M1, 0);   // 角度环(增量式 0.1/0/0)
A6020_speed = PID_Calc(&all_motor_pid.pid_follow_speed, yaw.speed_rpm, A6020_angle); // 速度环(25/3.5/0)
```

> 意义：当云台 yaw 电机被外力拨转（非遥控驱动），底盘自动旋转跟上，
> 使底盘始终"正对"云台指向。A6020_speed 后续加到四个轮速上（÷2）。

**遥控速度采集（键盘/摇杆叠加）：**

```c
x = RC->rc.ch[2] - FlagCheck(KEY_A) * 660 + FlagCheck(KEY_D) * 660;  // 左右
y = RC->rc.ch[3] + FlagCheck(KEY_W) * 660 - FlagCheck(KEY_S) * 660;  // 前后
```

**斜坡平滑（Ramp_function）：**

```c
x2 = Ramp_function(66, x, x2, 6, 0);   // 66 死区，每周期 6 步进
y2 = Ramp_function(66, y, y2, 6, 0);
```

**麦轮解算（标准公式）：**

```c
sin = y2 / sqrt(x2² + y2²);
cos = x2 / sqrt(x2² + y2²);
pwm0 = MAX(|x2|, |y2|);                    // 取较大者保证满速
pwm1 = pwm0 * (sin + cos);   // 左前
pwm2 = pwm0 * (sin - cos);   // 右前
pwm3 = pwm0 * (sin - cos);   // 左后
pwm4 = pwm0 * (sin + cos);   // 右后
// 映射到电机速度范围
RemoteXxxSpeed = pwmX * MaxGivenSpeed / 660;   // ±660 → ±7500
```

> ⚠️ 注意：pwm3/pwm4 赋值与 pwm1/pwm2 重复（同 sin∓cos），
> 实际形成"前左=后右、前右=后左"的 X 型分配，仅支持平移，不支持旋转分量——
> 旋转由 A6020 跟随修正量提供。移植时按新底盘运动学重写这四行。

### 1.5 小陀螺模式 chassis_set_v

```c
if (chassis_mode == CHASSIS_VECTOR_revolve) {
    // 摇杆输入经一阶低通（0.8 旧 + 0.2 新），×5 放大
    vx = 0.8*last_vx + 0.2*(RC->rc.ch[2] * 5);
    vy = 0.8*last_vy + 0.2*(RC->rc.ch[3] * 5);
    // 键盘模式：W/S/A/D 直接给 ±v_max(4000)
    ...
    // （注释掉的 yaw 角度旋转矩阵未启用）
    // 平移分量分配 + 自旋分量 v_revolve 全加
    chassis_set_v1 = vy1 + vx1 + v_revolve;
    chassis_set_v2 = -vy1 + vx1 + v_revolve;
    chassis_set_v3 = vy1 - vx1 + v_revolve;
```

### 1.6 PID 与功率限制 ChassisController → ChassisPidCtr

```c
ChassisController():
    四个给定速度限幅到 ±MaxGivenSpeed(7500)
    后两轮取负（"方向相反"）
    ChassisPidCtr(左前, 左后, 右前, 右后)

ChassisPidCtr():
    get_chassis_power_and_buffer(&Power, &Power_Buffer);  // 读裁判系统
    Power_Buffer = 50.0f;   // ⚠️ 被写死！实际没启用裁判系统功率缓冲

    follow 模式：目标速度 = 麦轮给定 + A6020_speed/2（跟随修正）
        LefUpFinal = PID_Calc(pid_front_right, front_left.speed_rpm, LefUpTarspd + A6020_speed/2)
        RigUpFinal = PID_Calc(pid_front_left,  front_right.speed_rpm, LefDoTarspd + A6020_speed/2)
        LefDoFinal = PID_Calc(pid_back_left,   back_left.speed_rpm,  RigUpTarspd + A6020_speed/2)
        RigDoFinal = PID_Calc(pid_back_right,  back_right.speed_rpm, RigDoTarspd + A6020_speed/2)

    revolve 模式：目标 = chassis_set_v1~v4 / 2

    功率限制（buffer < 50 才生效，当前被写死 50 永不触发）：
        MergeFinal = Σ|四输出|
        Limit = buffer² × PowerLimtParam(6.0)
        四输出按 Limit/MergeFinal 等比缩放
```

> ⚠️ 注意：PID 对象与反馈电机名存在错位（front_right PID 反馈 front_left 等），
> 命名混乱但最终四轮分别闭环。移植时按新底盘接线重新对齐。
> 底盘速度环 PID 参数（pid_init.c）：P=5, I=0.2, D=1，位置式，max_out=12000, max_iout=100。

### 1.7 Ramp_function 斜坡函数

```c
int16_t Ramp_function(int16_t delta_Min,   // 死区 66
                      int16_t target,      // 目标速度
                      int16_t now,         // 当前平滑值
                      int16_t ramp_Coeff,  // 每周期步进 6
                      uint8_t mode)        // 0
{
    Lenght = target - now;
    if (|Lenght| < 66) return target;         // 死区内直接到位
    if (mode==0 && target<0 && |Lenght|>660)  // 负向大跳变 → 直接砍到 1/3（急刹）
        return target / 3;
    return now ± ramp_Coeff;                   // 逐周期爬坡
}
```

## 5. 移植要点与老版本已知坑

1. **运动学必须重写**：老版是麦轮 X 型分配（且只支持平移），新版串腿底盘
   应使用自己的运动学（差速/履带式），`chassis_set_control` 里的
   sin/cos 分配公式不适用，但函数结构、数据流（遥控→斜坡→解算→PID→CAN）不变。
2. **老版麦轮解算有 bug**：pwm3/pwm4 复制了 pwm1/pwm2 的值，四轮实际只有两个自由度。
3. **revolve 模式平移失效**：vy1/vx1 旋转矩阵被注释，平移恒为 0。
4. **功率限制被写死**：`Power_Buffer = 50.0f` 使限功率分支永不触发，RMUL 参赛需接真裁判系统数据。
5. **PID 对象与反馈错位**：front_right PID 反馈 front_left 等，移植时对齐命名。
6. **A6020_M=1300 是标定值**：yaw 电机中位编码器值，换电机/装轴后需重新标定；
   新版可用上电读一次编码器自动标定替代硬编码。
7. **安全逻辑要保留**：DBUS 掉线发零 + 右拨杆 DOWN 锁底盘 + 目标限幅，这套保护在新版必须等价实现。
8. **斜坡函数 Ramp_function** 是老版手感的核心（66 死区 + 6 步进），建议原样保留参数，
   调参入口集中。
9. 老版本是 GBK 编码，直接复制文件到新版会乱码——**必须重写为 UTF-8 带 BOM**（按新版 CLAUDE.md 约定）。

### 6.1 模块划分（比老版更清晰）

- `chassis_task.c`：任务骨架（__weak 弱函数：Publish / Init / HandleException /
  SetMode / Observer / Reference / Console / SendCmd，按底盘类型由具体实现覆盖）
- `chassis_mecanum.c/h`：麦轮实现（CHASSIS_TYPE==CHASSIS_MECANUM_WHEEL 时编译）
- `chassis_omni.c/h`：全向轮实现（CHASSIS_TYPE==CHASSIS_OMNI_WHEEL 时编译）
- `robot_param_mecannum.h`：**全部参数集中在一个头文件**（物理参数 / PID / 遥控参数 / 电机方向）
- `motor.c/h`：电机抽象层（Motor_s 统一 3508 / 2006 / 6020 / 赛博齿轮）

### 6.2 标准麦轮逆运动学（ChassisConsole，修正老版 bug 的关键）

```c
// vx,vy 单位 m/s；wz 单位 rad/s；R=WHEEL_RADIUS 轮半径；L=WHEEL_CENTER_DISTANCE 轮心到中心距
// 右手系：前进=x，左=y，逆时针旋转 wz 为正；direction=±1 为每轮接线方向
set[0] = ( sqrt(2)/2*(vx - vy) - L*wz ) / R * ratio * direction;   // 左前
set[1] = ( sqrt(2)/2*(vx + vy) - L*wz ) / R * ratio * direction;   // 右前
set[2] = ( sqrt(2)/2*(vx - vy) + L*wz ) / R * ratio * direction;   // 左后
set[3] = ( sqrt(2)/2*(vx + vy) + L*wz ) / R * ratio * direction;   // 右后
```

与老版对比：

| 项目 | 老版（橙子） | StandardRobotpp |
|------|-------------|-----------------|
| 自由度 | 仅平移 2 自由度（pwm3/4 复制 pwm1/2，bug） | 完整 3 自由度（平移+旋转） |
| 旋转分量 | FOLLOW 用速度环输出近似叠加 | 解算含 L*wz 项，数学正确 |
| 单位 | 遥控值直接映射 RPM（±7500） | 物理单位 m/s、rad/s，换算在电机层 |
| 接线方向 | 写死在解算符号里 | **每轮 direction(±1) 参数化**，改宏即可 |

### 6.3 FOLLOW 模式（底盘跟随云台）正确算法

```c
// yaw_delta = loop_fp32_constrain(yaw电机当前位置 - YAW_MID, -PI, PI)  单位 rad
// 1) 平移速度旋转到云台/世界系（解决"推杆方向随车头转"问题）
reference.vx = rc_vx * cos(yaw_delta) - rc_vy * sin(yaw_delta);
reference.vy = rc_vx * sin(yaw_delta) + rc_vy * cos(yaw_delta);
// 2) 旋转分量用 PID 把偏差归零（底盘自动转正）
reference.wz = PID_calc(&follow_pid, 0, yaw_delta);   // 200/0.3/0，max_out=2.0 rad/s
```

老版做法是把 follow 速度环输出直接加到四轮 RPM（近似），
StandardRobotpp 的旋转矩阵 + wz PID 才是标准做法，新版建议采用。

### 6.5 模式切换（ChassisSetMode）

```c
if (DBUS掉线 || s[0]==DOWN || 云台未初始化完成) mode = CHASSIS_LOCK;
else if (s[0]==MID) mode = (spin_flag ? CHASSIS_SPIN : CHASSIS_FOLLOW);  // SHIFT 键翻转 spin_flag
else if (s[0]==UP)   mode = CHASSIS_SPIN;
```

老版用右拨杆 s[1] 切模式 + F/R 键，StandardRobotpp 用左拨杆 s[0] + SHIFT 键。
新版按老版习惯（s[1]）保留，LOCK 条件值得借鉴（云台未初始化完成也锁底盘）。

### 6.6 键盘控制（W/S/A/D）

- 键盘优先于摇杆：有键盘输入时目标速度 = 低通滤波爬升（alpha 0.005）× 最大速度
- 无键盘输入时用摇杆（死区 ±5，/660 归一化 × 最大速度 2 m/s）
- omni 版用 x_time/y_time 计数线性爬升（每周期 0.004/0.002）

### 6.7 参数集中化（robot_param_mecannum.h，移植借鉴重点）

```c
#define WHEEL_1_ID (1)             // CAN ID
#define WHEEL_1_CAN (1)            // CAN 口
#define WHEEL_1_MOTOR_TYPE DJI_M3508
#define WHEEL_1_DIRECTION (1)      // ★ 接线方向：轮子装反只改这里 ±1
#define WHEEL_1_RATIO (19)         // 3508 减速比 19:1
#define WHEEL_1_MODE (0)
#define WHEEL_RADIUS 0.08f         // 轮半径 (m)
#define WHEEL_CENTER_DISTANCE 0.304f  // 轮心到中心距 (m)
```

**这正是「接线确定后只改参数区」的落地样板**：方向 / 轮序 / 尺寸全部宏参数化，
接线变了改宏，不动解算主体。
