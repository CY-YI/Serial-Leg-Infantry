## 二、接手后的第一件事（按序执行）

### 1. 架车方向 + 闭环验证（四轮悬空！）
- 操作：右拨杆拨 **MID** 位 → 轻推摇杆
- 核对方向（对照 `01_底盘需求文档.md` §5 验收标准）：
  - 推杆向前 → 四轮同向转动
  - 推杆向左 → 左前/右后反转、右前/左后正转
  - 拨杆 UP（小陀螺）→ 自旋 + 摇杆平移同时有效
  - 拨杆 DOWN → 四轮立即停
- **方向修正入口**：只改 `application/chassis.h` 的方向参数区
  （`WHEEL_FL/FR/BL/BR_DIRECTION` 宏：某轮反转→该宏取负；轮序错位→交换宏）；
  **禁止改解算主体公式**
- ⚠️ **闭环已启用**：方向取反会导致正反馈跑飞（一推杆就狂转、松杆不停）→ 手放 DOWN 随时切断
- VOFA 观察：`chassis_stage`(1-6)、`chassis_loop_count`(≈500/s)、`chassis_tick_delta`(≈2ms)、
  `chassis_vx/vy/v_rot`、`chassis_yaw_delta`、`yaw_mid_deg`

### 2. 验证 FOLLOW 跟随
- 手拨 yaw 电机 / 转云台 → 底盘应自动转回正对云台
- `yaw_mid_deg` 应为**实测中值**；若恒为 57.1°，说明 yaw 反馈离线、回退了硬编码

### 3. 验证掉线保护
- 推杆让轮子转 → **拔掉接收机** → 0.1s 内四轮停
- 插回后需重新拨杆才动（上电即 LOCK 的安全设计）

## 五、操作规约速查（给 Agent 的坑位提醒）

1. **编码**：所有源文件 UTF-8 带 BOM。**用 Write 整体覆盖文件后必须补 BOM**
   （Write 不保留 BOM）：`head -c 3 文件 | xxd` 应见 `efbbbf`。
2. **改代码位置**：`Core/` 下只能写 USER CODE 块内；`application/` 可直接改。
3. **编译**：两条路径
   - **Keil 图形界面**（交付前必做）：`MDK-ARM/Serial Leg Infantry.uvprojx`
   - **命令行 armcc**（日常快速质检，不用开 Keil）：
     `D:\keil5\ARM\ARMCC\Bin\armcc.exe`（V5.06 update 7 build 960）
     ```
     armcc --c99 -c --cpu Cortex-M4.fp ^
       -DUSE_HAL_DRIVER -DSTM32F407xx -DARM_MATH_CM4 ^
       -D__FPU_USED=1U -D__FPU_PRESENT=1U -D__CC_ARM ^
       -ICore\Inc -IDrivers\STM32F4xx_HAL_Driver\Inc -IDrivers\CMSIS\Device\ST\STM32F4xx\Include ^
       -IDrivers\CMSIS\Include -IMiddlewares\Third_Party\FreeRTOS\Source\include ^
       -IMiddlewares\Third_Party\FreeRTOS\Source\portable\RVDS\ARM_CM4F ^
       -IMiddlewares\Third_Party\FreeRTOS\Source\CMSIS_RTOS ^
       -Iapplication -Ibsp -Ibsp\devices -Ialgorithm\control_algorithm ^
       -Ialgorithm\optimization_algorithm -ITEST ^
       application\chassis.c -o %TEMP%\chassis.o
     ```
     新增源文件仍需登记进 `.uvprojx`（参考 `tools/add_chassis_to_keil.py`）。
4. **编辑老文件**：Tab/空格混用，Edit 字符串匹配易失败 → 结构性/批量修改写成
   `tools/` 下脚本（先试运行再 `--apply`，自动备份），如 `tools/fix_pid_maxiout.py`。
5. **终端中文**：Python 输出加 `PYTHONIOENCODING=utf-8`；bash 内嵌不要用反引号
   写代码片段（会被命令替换吞掉，此前损坏过一次文档）。
6. **破坏性操作**：先试运行、显示对照，用户确认后执行（CLAUDE.md §七）。
