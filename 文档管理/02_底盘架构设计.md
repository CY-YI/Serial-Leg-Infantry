## 3. 单位与坐标系约定（关键决策）

| 量 | 单位 | 依据 |
|----|------|------|
| 速度环目标/反馈 | **RPM（电机轴）** | 与现有 `speed_rpm` 反馈、pid_init 参数（5/0.2/1，max_out 12000）兼容，沿用老版体系 |
| 麦轮解算输入 | vx/vy（RPM 平移分量）、v_rot（RPM 旋转等效轮速） | 标准公式退化为纯代数加减 |
| yaw_delta | °（度），归一化 ±180 | 与现有 `motor.angle`（°）一致，进三角函数前转弧度 |
| 坐标系 | 老版约定：ch2=左右(x)，ch3=前后(y)，符号 TODO-接线标定 | 实车调 |

麦轮解算（RPM 体系下的标准公式）：

```c
// vx,vy = 平移分量(RPM)；v_rot = 旋转等效轮速(RPM)
// direction[4] = 每轮接线方向(±1)，参数区定义
set[0] = ( (vx - vy)/√2 - v_rot ) * direction[0];   // 左前
set[1] = ( (vx + vy)/√2 - v_rot ) * direction[1];   // 右前
set[2] = ( (vx - vy)/√2 + v_rot ) * direction[2];   // 左后
set[3] = ( (vx + vy)/√2 + v_rot ) * direction[3];   // 右后
```

> 注：严格公式是 `L·wz/R` 换算成 RPM 再乘减速比，RPM 体系下 L/R/减速比
> 全部折算进 v_rot 的比例系数 `SPIN_RPM_PER_RAD`（参数区宏），
> 数学等价、参数集中。

## 5. 模块接口约定（全部复用现有，零改动）

| 接口 | 提供方 | 用法 |
|------|--------|------|
| `get_motor_control_point()` | bsp_can.c | 读 `can1_motors.front_left/right/back_left/back_right.speed_rpm`（反馈）与 `can1_motors.yaw.angle`（yaw_delta） |
| `CAN_cmd_chassis(i1,i2,i3,i4)` | bsp_can.c | 发送四轮电流，槽位顺序 (前左,前右,后左,后右) |
| `get_remote_control_point()` | remote_control.c | ch2/ch3、s[1]、key.v、鼠标 |
| `all_motor_pid` + `PID_calc` | pid_init.c / pid.c | 复用 `pid_front_right/left/back_left/back_right` 四槽位 + `pid_follow_angle/speed` |
| `get_imu_angle_point()` | INS_task | 预留：SPIN 模式可选 IMU 闭环（Could-have，先不用） |

**yaw 电机中值标定**（Should-have #9，替代硬编码 1300）：
上电后底盘静止期间采集 `can1_motors.yaw.angle` 均值（500ms 窗口），
存入 `yaw_mid_deg` 全局量；采集失败则回退硬编码 `A6020_M=1300` 换算值。
`yaw_delta = normalize_angle(yaw.angle - yaw_mid_deg)`。

## 6. 数据流（每 2ms 周期）

```
chassis_task
 ├─ chassis_set_mode      RC.s[1] / DBUS时间戳 / F键 → FOLLOW | revolve | LOCK
 ├─ chassis_set_control   (FOLLOW) 摇杆+键盘 → Ramp → vx/vy(RPM)
 │                        yaw_delta → 旋转矩阵(平移) + follow PID(v_rot)
 ├─ chassis_set_v         (revolve) 摇杆低通+键盘 → vx/vy(RPM) + V_REVOLVE
 ├─ ChassisController     四轮目标限幅 ±MAX_GIVEN_SPEED
 │                        麦轮逆运动学 → set[4](RPM)   ← 参数区 direction 生效处
 ├─ ChassisPidCtr         PID_calc(速度环) ×4 → 电流值
 │                        功率限制占位（buffer≥50 跳过）
 └─ CAN_cmd_chassis       0x200 四轮电流（掉线/LOCK → 全零）
```

## 7. FreeRTOS 注册（freertos.c，仅 USER CODE 块内）

```c
osThreadDef(chassis, chassis_task, osPriorityHigh, 0, 512);
chassisHandle = osThreadCreate(osThread(chassis), NULL);
```

优先级 High（与 gimbal 同级，低于 Realtime 的 INS_task）；
栈 512 字（老版同值，含 cos/sin 浮点运算余量）。

## 8. 掉线检测设计（简化版，替代完整 detect_task）

在 remote_control.c 的 `sbus_to_rc()` 解析成功后记录 `rc_last_update_tick = HAL_GetTick()`；
chassis.h 暴露 `rc_is_offline()`：`HAL_GetTick() - rc_last_update_tick > 100ms` → 判掉线。
chassis 与后续 gimbal/friction 共用此接口。
