## 1. M3508 电机官方参数（修正仿真模型的依据）

来源：DJI 官方产品页与《RoboMaster M3508 直流无刷减速电机使用说明》、
《C620 无刷电机调速器》手册（robomaster.com 下载区）。

| 参数 | 值 | 对仿真的意义 |
|------|-----|-------------|
| 减速比 | **3591/187 ≈ 19.2:1** | 仿真 WHEEL_RATIO=19 ✓ 确认 |
| 机械时间常数 | **49 ms** | τ 扫参 0.05~0.15s 起点正确 ✓ |
| 空载转速 | 482 rpm（输出轴）@ 0.78A | 空载 K ≈ 482×19.2/0.78A ≈ 14 RPM/电流单位（16384=20A） |
| 额定转速 | 469 rpm（输出轴）@ 3 N·m / 10A | 额定负载 K ≈ 1.1 RPM/单位电流 |
| 转矩常数 | 0.3 N·m/A | 堵转电流 ≈ 4.5/0.3 = 15A（≈12300 电流单位，贴近 C620 上限） |
| 额定/最大功率 | 150W / 220W | 功率限制参考 |
| 极对数 | 7 | 转速换算用 |
| C620 | 20A 持续、CAN 1Mbps、电流量程 16384 | 仿真 MAX_OUT=12000 留有 25% 余量 ✓ |

**仿真模型修正结论**：
- 一阶惯性 τ 取 **0.05s**（官方机械时间常数 49ms）为主工况
- K 随负载在 1.1~14 之间大幅变化（线性模型局限）：空载架车 K≈10~14，
  落地满载 K≈1~2。仿真用 K=5（轻负载）得出的 max_iout=1500 结论在
  **全负载范围都安全**（K 越小需求电流越大，1500 积分限幅余量充分）。
- 等比缩放限幅（见 §3）在满载低 K 时更关键：单轮目标可能远超 MAX_GIVEN_SPEED。

## 3. DJI 官方开源（"原版"）架构分析

仓库：[RoboMaster/Development-Board-C-Examples](https://github.com/RoboMaster/Development-Board-C-Examples)
（2020-01-07 官方开源，开发板 C 型配套教程；镜像：PennState-RoboX/DJI-Development-Board-C-Examples-）

- `17.chassis_task`：底盘任务教学例程（**两层架构**）
- `20.standard_robot`：完整标准步兵工程（含 referee / power_control / oled 等）
- 教程文档：`RoboMaster开发板C型嵌入式软件教程文档.pdf`（仓库内）

### 3.1 官方两层架构（比橙子版更清晰的分层）

```
chassis_behaviour.c  行为层：遥控/拨杆 → 行为模式(ZERO_FORCE/NO_MOVE/
                     INFANTRY_FOLLOW_GIMBAL_YAW/NO_FOLLOW_YAW/OPEN...)
                     → 输出 vx_set/vy_set/angle_set 三目标量
chassis_task.c      执行层：反馈更新(四轮反算 vx/vy/wz) → 麦轮解算
                     → 等比限幅 → 四轮速度环 PID → CAN 发送
```

橙子版（用户熟悉的老版）是官方两层压成的单文件 chassis.c；
StandardRobotpp 把官方两层拆成 chassis_mecanum + chassis_task 弱函数骨架。
**三种架构一脉相承**，我们沿用橙子版单文件（方案 A 已定），
但内部数据流与官方一致：行为 → 三目标量 → 解算 → PID → 发送。

### 3.2 官方麦轮解算公式（与 StandardRobotpp 等价，符号体系不同）

```c
// 官方形式（vx 前进、vy 左移、wz 逆时针为正，右手系）
wheel_speed[0] = -vx - vy + (WZ_SCALE-1)*L*wz;   // 左前
wheel_speed[1] =  vx - vy + (WZ_SCALE-1)*L*wz;   // 右前
wheel_speed[2] =  vx + vy + (-WZ_SCALE-1)*L*wz;  // 左后
wheel_speed[3] = -vx + vy + (-WZ_SCALE-1)*L*wz;  // 右后
// WZ_SCALE 为旋转分量缩放系数（云台靠前，前轮慢后轮快）
// √2 等系数被吸收进 CHASSIS_MOTOR_RPM_TO_VECTOR_SEN 灵敏度宏
```

### 3.3 官方实现中值得借鉴的 3 个设计（并入 MVU-2）

1. **等比缩放限幅**（优于老版逐轮截断）：
   ```c
   if (max_vector > MAX_WHEEL_SPEED) {
       vector_rate = MAX_WHEEL_SPEED / max_vector;
       for (i=0; i<4; i++) wheel_speed[i] *= vector_rate;
   }
   ```
   四轮按同一比例缩小，**保持运动方向不变**；老版逐轮截断会改变合速度方向。
2. **一阶低通替代斜坡**：官方注释明确"first order low-pass replace ramp function"，
   且**停止指令直接清零不滤波**（急停不拖尾）。新版保留老版 Ramp（你熟悉），
   但停止清零逻辑采用官方做法（MVU-2 实现）。
3. **摇摆功能（swing）**：FOLLOW 模式下按 SWING_KEY 做 sin 摆动角度设定
   （摆动时底盘像人一样左右晃身躲避弹丸）——列为 Could-have，框架预留。

### 3.4 官方 FOLLOW_GIMBAL_YAW 与各版本对比

| 实现 | FOLLOW 旋转控制方式 | 备注 |
|------|--------------------|------|
| DJI 官方 | angle_set 角度设定 + 角度环 PID（相对角度），旋转矩阵注释掉 | 依赖 yaw 电机相对角度 |
| 橙子版 | follow 速度环输出直接加到四轮转速 | 近似做法 |
| StandardRobotpp | yaw_delta 旋转矩阵平移 + wz PID 归零 | 标准做法（我们采用） |
